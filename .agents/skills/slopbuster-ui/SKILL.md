# Slopbuster UI (Anti-Slop Presentation Design)

## Core Heuristics
1. **Ban the Monolithic Corporate Whiteboard:**
   - Avoid flat stark white or sterile flat gray cards with standard `box-shadow: 0 4px 6px rgba(0,0,0,0.1)`.
   - Use warm archival ledger palettes: dark forest green (`#0d1f18`), aged parchment (`#f7f2e7`), warm sepia touches, and muted sage.
2. **Organic Tactile Craft:**
   - Cards in an archival scrapbook aren't computer-straight: apply subtle micro-rotations (`transform: rotate(-0.35deg)` to `rotate(0.4deg)`).
   - Use tactile physical affordances: semi-translucent masking tape strips, embossed photo-album corners, and contact-sheet stamps.
3. **Typography Harmony:**
   - Pair classical editorial serifs (EB Garamond, Cinzel) with monospaced archival typewriter fonts (JetBrains Mono) for metadata labels.
