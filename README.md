# Smoot-Hawley: Did Protectionism Protect American Farmers?
### AP Microeconomics Interactive Presentation Website

An interactive, presentation website analyzing the economic effects of the **Smoot-Hawley Tariff Act of 1930**, built for AP Microeconomics.

* **Authors:** Miguel S, Chlono K, Hayden W, Ramata D
* **Live Site:** [https://valrivn.github.io/Ap-Micro-Website/](https://valrivn.github.io/Ap-Micro-Website/)

---

## Presentation Highlights & Nuances

1. **Dual-Mode Presentation Experience**:
   - **Slide Deck Mode (Default)**: Fullscreen slide-by-slide presentation with smooth transitions, progress tracking, and keyboard shortcuts (`←`/`→`, `Space`, `F` for fullscreen).
   - **Document Scroll Mode**: Single-click toggle (`D`) to read the entire presentation as a continuous academic monograph.
2. **Interactive AP Micro Welfare Graph**:
   - Dynamic SVG showing Price ($P$), Quantity ($Q$), Domestic Supply ($S$), and Domestic Demand ($D$).
   - Toggle between **World Free Trade ($P_w$)** and **With Tariff ($P_T$)**.
   - Live highlight overlays for:
     - **Consumer Surplus (CS)** (Blue)
     - **Producer Surplus (PS)** (Pink)
     - **Government Tariff Revenue (TR)** (Green)
     - **Deadweight Loss (DWL)** (Production and Consumption distortions)
   - Original hand-drawn Canva slide diagram viewable via an archival modal.
3. **Primary Source Political Cartoon Exhibit**:
   - Authentic 1900s lithograph *"Excessive Protection on the Tariff Wall"* (Humpty Dumpty) by Udo J. Keppler (Puck / Library of Congress / American-German Institute).
   - Clickable interactive hotspots exploring the symbolism of the tariff wall, congressional logrolling, and the agricultural credit collapse.
4. **Verbatim Content Preservation**:
   - Preserves 100% of the slide text, historical facts, citations, and New Deal / RTAA analysis from the team's Canva deck without alteration.

## Keyboard Controls for Presenters & Graders

| Key | Action |
| :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>↓</kbd> | Advance to next slide |
| <kbd>←</kbd> / <kbd>↑</kbd> | Return to previous slide |
| <kbd>F</kbd> | Toggle Fullscreen mode |
| <kbd>D</kbd> | Switch between Slide Deck Mode & Document Scroll Mode |
| <kbd>1</kbd> - <kbd>5</kbd> | Jump straight to specific slide |
| <kbd>?</kbd> | Open Presenter & Teacher Guide |
