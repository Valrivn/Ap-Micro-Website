# Smoot-Hawley: Did Protectionism Protect American Farmers?
### AP Microeconomics Interactive Presentation Website

An interactive, museum-grade presentation website analyzing the economic effects of the **Smoot-Hawley Tariff Act of 1930**, built for AP Microeconomics.

* **Authors:** Miguel S, Chlono K, Hayden W, Ramata D
* **Live Website:** [https://valrivn.github.io/Ap-Micro-Website/](https://valrivn.github.io/Ap-Micro-Website/)
* **GitHub Repository:** [https://github.com/Valrivn/Ap-Micro-Website](https://github.com/Valrivn/Ap-Micro-Website)

---

## Presentation Highlights & Nuances

1. **Artistic Museum-Grade Design**:
   * Authentic hand-drawn chalk currency doodles (`$`, `£`, `€`) and directional arrows matching Canva Slide 1.
   * Translucent organic sage green corner ribbon loops framing slides (matching Canva Slides 2, 4, 6, and 7).
   * Torn-paper and deckle-edge header textures.
2. **Dual-Mode Presentation Experience**:
   * **Slide Deck Mode (Default)**: Fullscreen slide-by-slide presentation with smooth transitions, progress tracking, and keyboard shortcuts (`←`/`→`, `Space`, `F` for fullscreen, `1`–`6` direct jumps).
   * **Document Scroll Mode**: Single-click toggle (`D`) to read the entire presentation as a continuous academic monograph.
3. **Slide 2: Domestic Market Welfare Analysis**:
   * **Interactive Vector Model**: Dynamic SVG with ample axis padding, clean HTML subscript typography (`P`<sub>W</sub>, `P`<sub>T</sub>, `Q`<sub>s</sub>, `Q`<sub>st</sub>, `Q`<sub>dt</sub>, `Q`<sub>d</sub>), and live surplus toggles (CS, PS, Tariff Revenue, DWL).
   * **In-Place Canva Inspiration Tab**: View the authentic hand-drawn Canva Slide 4 diagram side-by-side.
4. **Slide 4: Interactive Political Cartoon Exhibit**:
   * Authentic 1900s lithograph *"Excessive Protection on the Tariff Wall"* (Humpty Dumpty) by Udo J. Keppler (Puck / Library of Congress / American-German Institute).
   * Clickable interactive hotspots exploring the symbolism of the tariff wall, congressional logrolling, and the agricultural credit collapse.
5. **Slide 5: Quality of Life & Longitudinal Trade Impact**:
   * **Longitudinal US Trade Line Chart (1928–1940)**: Graphs the 70% collapse in US imports (\$4.4B down to \$1.3B) and post-1934 RTAA recovery.
   * **Quality of Life Index Dashboard**:
     - *Farm Parity Ratio / Purchasing Power Index* (92 $\to$ 58).
     - *Farm Mortgage Foreclosure & Rural Banking Insolvency* (38.8% distress, 9,000+ bank failures).
     - *Consumer Price Index (CPI) Deadweight Loss* on 20,000 basic goods.
6. **Full Original Canva Deck Carousel**:
   * Click the **"Original Canva Deck"** button in the header to browse all 7 high-resolution Canva project slides in an archival modal with thumbnail navigation.

## Keyboard Controls for Presenters & Graders

| Key | Action |
| :--- | :--- |
| <kbd>→</kbd> / <kbd>Space</kbd> / <kbd>↓</kbd> | Advance to next slide |
| <kbd>←</kbd> / <kbd>↑</kbd> | Return to previous slide |
| <kbd>F</kbd> | Toggle Fullscreen mode |
| <kbd>D</kbd> | Switch between Slide Deck Mode & Document Scroll Mode |
| <kbd>1</kbd> - <kbd>6</kbd> | Jump straight to specific slide |
| <kbd>?</kbd> | Open Presenter & Teacher Guide |
| <kbd>Esc</kbd> | Close modals |
